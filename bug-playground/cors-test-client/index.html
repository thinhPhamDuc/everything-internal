Bug Playground - Client test Bug #4 (CORS & Routing)

Origin hiện tại của trang này:
Mở trực tiếp bằng file:// -> origin là null, sẽ LUÔN bị chặn CORS (đúng bug mặc định của gateway). Muốn thử trạng thái "đã fix", chạy python3 -m http.server 5500 trong thư mục này, mở http://localhost:5500, rồi set GATEWAY_CORS_ALLOWED_ORIGIN=http://localhost:5500 cho gateway-service (xem README).
Mở DevTools Console (F12) TRƯỚC khi bấm nút - lỗi CORS chỉ hiện ở Console, không hiện trong khung log dưới (đây chính là đặc điểm cần nhớ: JS code không thể "bắt" được lỗi CORS bằng try/catch bình thường, fetch() chỉ báo "Failed to fetch").
